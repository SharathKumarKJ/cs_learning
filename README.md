# CS Learning

A structured learning repository for senior data engineering preparation.

## Sections

- `python_data_engineering`: standalone Python programs from basics to senior-level patterns.
- `pyspark_interview_programs`: PySpark examples and interview question banks.
- `sql_problems_solutions`: SQL problems with solutions from basic to very advanced.
- `cloud_questions`: AWS, Azure, and cloud data engineering interview questions.
- `airflow_learning`: Airflow concepts, DAG examples, and production questions.
- `extra_learning`: supporting topics for senior data engineering interviews.

## Suggested learning order

1. Python data engineering basics
2. SQL basics to window functions
3. PySpark DataFrame APIs and optimization
4. Airflow orchestration
5. Cloud data engineering
6. Kafka, DBT, modeling, warehousing, and system design
