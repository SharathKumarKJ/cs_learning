# 100-Day Senior DE Study Plan

## Week 1-2: SQL foundations
- Daily 5 SQL problems (basic -> window functions).
- Cover joins, CTEs, aggregations, window functions.

## Week 3-4: Advanced SQL + warehousing
- Recursive CTEs, pivot/unpivot, MERGE, islands/gaps.
- Star schema, SCD types, fact/dim grain.

## Week 5-6: Python for DE
- File handling, OOP, decorators, generators, async.
- Build mini ETL, retry, config-driven pipeline.

## Week 7-9: PySpark deep dive
- DataFrame API, joins, windows, partitions, shuffle, AQE.
- Build SCD2, CDC merge, broadcast/salting examples.
- Streaming with watermark and checkpointing.

## Week 10-11: Airflow
- DAG design, dynamic mapping, sensors, deferrable operators.
- Production: secrets, deployment, observability.

## Week 12: Cloud (pick one deep)
- AWS / Azure / GCP / Snowflake.
- Data lake, warehouse, streaming, security, cost.

## Week 13: Lakehouse formats
- Delta, Iceberg, Hudi compare and use cases.

## Week 14: Modeling + governance
- Kimball, Data Vault basics, lineage, quality, contracts.

## Week 15+
- Mock interviews.
- System design (1 per week).
- Behavioral STAR stories (10 prepared).
