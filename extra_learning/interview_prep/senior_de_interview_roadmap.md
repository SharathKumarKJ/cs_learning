# Senior Data Engineer Interview Roadmap

## Python

- File handling, JSON, CSV, APIs, generators, decorators, logging, testing, packaging.
- Data quality, incremental loads, idempotency, retries, and schema validation.

## SQL

- Joins, aggregations, CTEs, window functions, recursive queries, query plans, and optimization.

## PySpark

- DataFrame API, joins, windows, partitioning, shuffle, skew, AQE, streaming, and production debugging.

## Cloud

- Data lake architecture, IAM, encryption, catalog, warehouse, streaming, orchestration, monitoring, and cost.

## Airflow

- DAG design, scheduling, sensors, operators, retries, backfills, deployment, and production reliability.

## System design

- Batch pipelines, streaming pipelines, CDC, lakehouse, data warehouse, quality framework, and metadata-driven ingestion.

## Behavioral topics

- Incident handling, stakeholder communication, mentoring, tradeoff decisions, ownership, and project leadership.

## Practice plan

1. Solve 5 SQL problems daily.
2. Write 1 Python data engineering utility daily.
3. Implement 2 PySpark transformations weekly.
4. Design 1 architecture scenario weekly.
5. Review one production incident or failure mode weekly.
